# Языковые папки + манифест — как устроена система (i18n)

> Это главный документ по структуре языков. Читается за 2 минуты.
> Смысл: **добавить язык = дописать одну строку в `languages.json` + положить папку.** Всё.

---

## Структура

Все языки живут в одной папке `langs/`. Рядом с игрой она лежит в
`BepInEx\plugins\OstraI18n\langs\`, в рабочей области — `C:\AIWorkspace\ostra_i18n\langs\`.

```
langs/
  languages.json          <- МАНИФЕСТ: какие языки поддержаны и в какой папке лежат
  lang_ru/                <- папка русского: ВСЁ для него внутри
    strings.json          <- строки интерфейса  { "GUI_OPTIONS_SAVE": "Сохранить", ... }
    gui.json              <- hardcoded/запечённый в префабах текст  { "Save": "Сохранить", ... }
    grammar.json          <- местоимения движка по падежам (6 форм: я/ты/он/она/они/оно)
    verbs.json            <- парадигмы глаголов движка (ключ = англ. токен "says")
    data/                 <- (опционально) нарративный контент: interactions, conditions...
  lang_de/                <- папка немецкого (та же структура)
    ...
  lang_zh/
    ...
```

---

## Манифест `languages.json`

Просто мапа "код языка -> папка":

```json
{
  "ru": "lang_ru",
  "russian": "lang_ru",
  "de": "lang_de",
  "zh": "lang_zh"
}
```

**Добавить язык:** дописываешь строку `"de": "lang_de"` и кладёшь папку `lang_de/`. Всё.
Плагин при запуске читает манифест, находит папку по активному языку и тянет из неё всё.

**Какой язык активен** — конфиг плагина `BepInEx\config\com.coreforge.ostra.i18n.cfg`,
параметр `Language = ru` (или `russian`). Поменял код → подтянулась другая папка.
Если код не найден в манифесте, плагин ищет папку `lang_<код>` по умолчанию.

## Что в каждом файле папки

| Файл | Формат | За что отвечает |
|---|---|---|
| `strings.json` | `{"GUI_KEY": "перевод"}` | Строки интерфейса (кнопки, заголовки) по ключу. Перекрывает `strings.json` игры. |
| `gui.json` | `{"English text": "перевод"}` | Текст НЕ из файлов игры: захардкоженный в коде + запечённый в префабах. Ключ = точная английская строка с экрана. |
| `grammar.json` | `{"pronouns": {"subj": [6 форм], "obj": [...], ...}, "you": "ты"}` | Местоимения движка подстановки `[us]`/`[them]`. 6 форм = [я, ты, он, она, они, оно]. |
| `verbs.json` | `{"says": {"present": [6 форм]}, "is": {"kind":"copula","omitPresent":true,...}}` | Спряжение глаголов движка. Ключ = англ. токен из шаблона ("says","is"). |
| `data/` | файлы по доменам | Нарративный контент (interactions, conditions, items...). Собирается в мод. |

Всё plain-text JSON, UTF-8 — редактируется любым редактором.

---

## Как это работает в игре

Плагин OstraI18n при запуске:
1. Читает `langs/languages.json` → находит папку активного языка.
2. Грузит из папки: `grammar.json` + `verbs.json` (движок грамматики), `strings.json`
   (строки GUI через патч GetString), `gui.json` (перехват отображаемого текста),
   + ставит кириллический fallback-шрифт.
3. Если в папке есть `data/` — она уходит в мод `Mods/lang_<код>/` (нарратив).

Игра не трогается (всё runtime/моды) → переживает обновления Steam.

## Жизненный цикл (для переводчика)

```
# в C:\AIWorkspace\ostra_i18n\tools\
python extract.py            # вытянуть свежий английский из игры -> lang_src/
python translate.py ru       # Qwen переведёт строки GUI -> langs/lang_ru/strings.json
python translate_gui.py ru   # Qwen переведёт hardcoded/префабы -> langs/lang_ru/gui.json
python package.py ru         # разложить langs/lang_ru/ по игре (плагин + мод) + манифест
```
Новый язык: `python translate.py de && python package.py de`, дописать grammar/verbs по
образцу lang_ru, и `"de": "lang_de"` в манифест.
