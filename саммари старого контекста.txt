# ПОЛНОЕ САММАРИ ПРОЕКТА: Ostranauts i18n System

Перепроверил контекст построчно. Ниже — исчерпывающая карта проекта: что изучено, что построено, что доказано вживую, и что осталось.

---

## 0. Суть проекта одной строкой

**Цель:** не перевод, а **СИСТЕМА i18n** для Ostranauts — переписанный грамматический движок подстановки токенов `[us]/[them]/[verb]`, папки на язык + манифест, пайплайн перевода, устойчивый к обновлениям игры. Перевод на RU — только первое доказательство работы системы; дальше — любые языки без вмешательства разработчика.

**Игра:** Unity **6000.3.10f1 (Unity 6) + Mono** (НЕ IL2CPP → код декомпилируется в чистый C# без обфускации). Путь: `F:\Games\Steam\steamapps\common\Ostranauts`.

**Статус на конец контекста:** система построена и **доказана вживую** (13 патчей, 0 ошибок, русская грамматика на реальных NPC, русские строки GUI в игре). В фоне шёл доперевод GUI-словаря через Qwen (batch 4/7, 121/191) и оркестрация пересборки релиза под новую папочно-манифестную структуру.

## 2. КАК РАБОТАЕТ ТЕКСТОВЫЙ ДВИЖОК ИГРЫ (главное)

### 2.1. Полный пайплайн подстановки
```
"[us] [adds] connection to [them]"            ← JSON-шаблон в данных игры
  ↓ LOAD
DataHandler.LoadMod читает data/tokens/{aliases, grammar, verbs}.json
  ↓
DataHandler.UnpackTokens → раскладывает в 3 ветки словарей:
    • aliases      (псевдонимы токенов)
    • categories   (грамматика/местоимения)
    • verbs        (спряжения)
  ↓
SetupDicts → препarsing шаблонов в токен-спаны (TokenData)
  ↓ RUNTIME
GrammarUtils.GetInflectedString(template, condOwner)   ← ТОЧКА ВХОДА
  ↓
PrepareString → привязка [us]/[them]/[3rd] к объектам (CondOwner)
  ↓
GenerateString → цикл по токен-спанам:
    Verb() / AttemptSubstitution() / AttemptProperName() / SetCase()
  ↓
StringBuilder → TextMeshPro (рендер на экран)
```

### 2.2. Класс `GrammarUtils` — ядро (30 методов, все сдамплены)
| Метод | Что делает | Критично для i18n |
|---|---|---|
| `GetInflectedString` | Точка входа всего движка | Патчится |
| `COToPOSIndex` | Местоимение из condition-флагов: `IsPlayer→you`, `IsMale→he`, `IsFemale→she`, `IsNB→they`, `!IsHuman→it`. Возвращает **6-значный POSIndex** | Нет падежей/родов — переписан |
| `Verb` | Выбор формы глагола по индексу местоимения (0=I, 1=you, 2=he, 3=she, 4=they, 5=it): you/they→база, остальные→singular. **Всего 2 формы (англ.)** | Переписан под 6+ форм |
| `AttemptSubstitution` | Подставляет ShortName или местоимение из таблиц | Переписан (склонение имён) |
| `AttemptProperName` | Обработка собственных имён | Патчится |
| `PrepareString` / `GenerateString` | Разметка токенов / сборка строки | Затронуты |
| `SetCase` | Регистр | Патчится |

### 2.3. Данные движка (формат уже готов под i18n!)
- **`tokens/grammar.json`** — таблицы местоимений (`subj/pos/obj/reflexive/contractIs…`) и поле **`"lang": "eng"`** ← формат данных СПРОЕКТИРОВАН под языковые пакеты, но код его игнорирует. **Это точка входа всей системы.**
- **`tokens/verbs.json`** — спряжения. Логика `UnpackTokens`: если у глагола 1 форма (`["adds"]`) — движок сам отрезает последнюю букву → база `add`; если 2 (`["does","do"]`) — берёт как есть. Итог: `dictVerbs[singular] = [singular, base]`. В шаблонах данных ~117 английских глаголов.
- **`tokens/aliases.json`** — псевдонимы.
- Параллельно таблицы местоимений **зашиты в `.cctor` GrammarUtils** (I/you/he/she/they/it × subj/pos/obj/reflexive/contractIs) — дублирование данных в коде, ещё одна точка переписывания.

### 2.4. Масштаб текста в игре
- **~145 000 строк** (~3.4M символов, ~688K слов) в **523 JSON-файлах**
- 30K диалоговых строк, 26K названий предметов, 882+ GUI-строк
- Токены в данных: `[us]`×7859, `[them]`×4120, `[3rd]`×707, `[is]`×864
- Синтаксис с категориями подтверждён: `[us:subj]` и т.п.

### 2.5. Зачатки локализации в игре (недопилены!)
- Класс `Localisation` (`get_language`/`set_language`), но `Get` — **заглушка, всегда "English"**.
- Классы `JsonLocalisedStrings` / `JsonLocalisedStringsRaw` (поле `strLanguage`) — существуют, но **нигде не читаются**.
- Консольная команда `language` принимает "English"/"Portuguese", пишет в `PlayerPrefs["Localisation"]` — механизм переключения заложен, файлов под него нет.
- Мод-система: `Mods/`, `loading_order.json`, `mod_info.json`, `ModLoader`, `DataHandler.LoadMod`. Путь модов: `settings.json → UserSettings.strPathMods`, иначе дефолт `Application.dataPath + "Mods/"`.

## 3. ЧТО ПЕРЕПИСАНО: плагин OstraI18n (BepInEx 6 + HarmonyX)

### 3.1. Файлы плагина
| Файл | Роль |
|---|---|
| `Plugin.cs` | Каркас + оркестратор (Awake-based: захват SynchronizationContext, фоновые потоки, `Application.runInBackground = true`, self-тесты) |
| `RuData.cs` | Загрузчик языковых пакетов → **переписан под манифест** (`langs/languages.json` + папки `lang_*`) |
| `Patches.cs` | Все Harmony-патчи грамматики + `GetStringPostfix` |
| `FontFallback.cs` | Шрифтовой fallback кириллицы |
| `GuiText.cs` | Runtime-перехват GUI-текста (хардкод + префабы) |

### 3.2. Полная карта патчей (финал: **13 патчей, 0 failed**)
| # | Цель | Тип | Что делает |
|---|---|---|---|
| 1 | `Localisation.Get` | postfix | Возвращает активный язык из конфига вместо хардкода "English" |
| 2 | `DataHandler.UnpackTokens` | патч | Грузит `grammar.json`/`verbs.json` из папки языка (не только eng) |
| 3 | `GrammarUtils.Verb` | патч | Русское спряжение: 6 форм настоящего + прошедшее по родам (вместо 2 англ. форм) |
| 4 | `GrammarUtils.AttemptSubstitution` | патч | Местоимения по падежам, склонение русских имён |
| 5 | `GrammarUtils.AttemptProperName` | патч | Имена собственные под язык |
| 6 | `TMP_Settings.get_instance` | патч | Подсадка `NotoSansGC-Regular SDF` в глобальный font-fallback → кириллица везде |
| 7 | `GetString` | postfix | GUI-строки берутся из `strings.json` папки языка (папка самодостаточна) |
| 8–13 | GUI-хуки (`GuiText`) | prefix на `TMP_Text.set_text` + postfix на `OnEnable` и др. | Ловят **ЛЮБОЙ** текст, попадающий на экран: хардкод из C# и запечённый в префабах/сценах. Режим дампа собирает все отображаемые английские строки в файл |

### 3.3. Дизайн русской грамматики (вместо англ. 6-позиционного POSIndex)
- **MorphContext**: род (м/ж/ср), число, лицо, одушевлённость.
- `grammar_rus.json`: 6 падежей + прошедшее время по родам; 8 категорий местоимений.
- `verbs_rus.json`: полная парадигма (6 форм наст. + 4 прош.); ключи = английские формы из шаблонов → даже непереведённые шаблоны спрягаются по-русски. 176 глаголов.
- Обратная совместимость: `[us]`, `[adds]` работают при `lang=eng`; новый синтаксис `[us:gen]` при `lang=rus`.
- **Устойчивость к обновлениям:** патчи через Harmony (файлы игры не правятся); защитный PatchRunner (нет метода → пропуск, ваниль остаётся); VersionGuard по хешу `Assembly-CSharp.dll`.

## 4. ШРИФТЫ (решено)

**Офлайн-анализ** (UnityPy + TypeTreeGeneratorAPI с тип-деревьями из игровых DLL): 43 legacy Font + **55 TMP_FontAsset SDF-атласов**.

| Шрифт | Кириллица |
|---|---|
| Roboto (12 начертаний) | ✅ 255/256 |
| Noto Sans / Liberation Sans | ✅ 256/256 |
| **NotoSansGC-Regular SDF** (в `resources.assets`) | ✅ **256/256 — уже в игре и уже в fallback-цепочках** `robotocondensedb SDF` и `Jura-Bold SDF` |
| MuseoModerno (логотип), PixelMid, Ac437 | ❌ нет (MuseoModerno требует замены на Roboto) |

**Решение:** патч №6 подсаживает NotoSansGC в глобальный fallback TMP → кириллица рендерится везде без перепайки атласов.

## 5. ФИНАЛЬНАЯ АРХИТЕКТУРА: папки на язык + манифест (последняя большая задача)

Требование пользователя: **всё в файлах, удобное для правки; добавить язык = дописать строку в манифест + кинуть папку.**

```
BepInEx\plugins\OstraI18n\langs\
├── languages.json          ← МАНИФЕСТ: { "ru": "lang_ru", "russian": "lang_ru" }
└── lang_ru\                ← папка языка, ВСЁ внутри:
    ├── grammar.json   (1 КБ)   местоимения движка по падежам
    ├── verbs.json     (32 КБ)  спряжения (176 глаголов)
    ├── strings.json   (122 КБ) 1179 строк интерфейса
    └── gui.json       (1 КБ)   хардкод/префаб-текст (дозаполняется Qwen)
```

**Добавление языка:** 1) кинуть `langs\lang_de\` с теми же 4 файлами; 2) дописать `"de": "lang_de"` в `languages.json`. Всё — плагин подтянет сам. Переключение — параметр `Language = de` в конфиге плагина. **Никаких правок кода.**

Подтверждено логом игры:
```
language 'Russian' -> lang_ru
pack Russian [lang_ru]: 8 pronoun cats, 176 verbs, 1179 strings, 24 gui
13 patches ok, 0 failed
```

## 6. ПАЙПЛАЙН ПЕРЕВОДА (инструменты, переводить можно без меня)

```
игра → extract.py → lang_src (англ. источник)
     → import_old.py (старый перевод как база)
     → translate.py <код> (Qwen-батчинг)
     → langs/lang_<код>/
     → package.py → готовый мод в игру
     → build_release.py → i18n_release для раздачи
```

| Инструмент | Что делает |
|---|---|
| `extract.py` | Извлекает английский источник из живого `strings.json` игры → `lang_src/strings.en.json` (1179 строк) |
| `import_old.py` | Импорт старого перевода: **927 из 928 ключей переиспользованы (покрытие 78.6%)**, устарел 1 ключ |
| `translate.py` | Qwen-перевод добивки, резюмеемый, батчи ~20 ключей, прогресс-лог |
| `package.py` | Языковая папка → мод (покрывает оба пути: плагин + мод-перекрытие `dictStrings`) |
| `build_release.py` | Сборка `i18n_release` (переписан под langs/-структуру) |

**Результат RU:** 1179/1179 GUI-строк (928 старых + 251 Qwen). Примеры качества: «Piracy→Пиратство», «Multiple accounts of murder→Множественные убийства».

## 7. GUI: анализ покрытия и рантайм-хук (ответ на «не всё в текстовых файлах!»)

Пользователь указал: часть GUI не в `strings.json`. Анализ декомпилята подтвердил:

| Источник | Объём | Покрытие |
|---|---|---|
| `GetString(...)` из strings.json | 555 ключей / 710 вызовов | ✅ мод + патч GetString |
| Хардкод в C# (литералы) | 145 уникальных, **138 НЕТ в strings.json** (chargen: "POINTS LEFT", "Choose Another Qualification", "At Large"; трейд: "Buy", "Not Wanted"; энкаунтер: "Link 1/2") | ⚠️ GUI-хук → gui.json |
| Запечено в префабах/сценах | Главное меню, "VIDEO SETTINGS", "AUDIO SETTINGS", "Autosave interval", "CONTENT WARNINGS" | ⚠️ GUI-хук → gui.json (дамп поймал 63 строки с одного экрана настроек) |
| Ключи GetString без записи в strings.json | 11 шт. (вернут UNKNOWN_STRING) | ⚠️ добавить |

**Решение:** `GuiText.cs` — рантайм-перехват всех `TMP_Text` (по образцу XUnity.AutoTranslator, но внутри нашего плагина): prefix на `set_text` + postfix на `OnEnable`. Режим дампа собирает реально отображаемые строки → консолидация в `gui.json` (с переиспользованием переводов мода) → доперевод Qwen (на конец контекста: **191 строка, в работе**).

## 10. ТЕХНИЧЕСКИЕ ГРАБЛИ (чек-лист для продолжения)

**BepInEx:**
- BepInEx **5.4 не работает** с Unity 6000.3 (старый doorstop, мгновенная смерть без логов)
- BepInEx 6.0.0-pre.2 — тоже падает
- ✅ Рабочий: **BepInEx 6.0.0-be.785** (bleeding edge, обновлённый doorstop)

**Сборка плагина (csproj):**
- `BaseUnityPlugin` в BepInEx 6 живёт в неймспейсе **`BepInEx.Unity.Mono`**
- Unity 6000: MonoBehaviour в `UnityEngine.CoreModule.dll` → ссылаться на **фасад `UnityEngine.dll`**
- `GlyphRenderMode` → **`UnityEngine.TextCore.LowLevel`** (не TextCore!)
- Доп. референсы: `TextCoreFontEngineModule`, `UnityEngine.UI`, `ScreenCaptureModule`, `Unity.TextMeshPro.dll`

**Headless (session 0) — критично для автотестов:**
- MCP работает в сессии 0 (SYSTEM) → GUI стартует невидимо, **player loop Unity заморожен без фокуса окна**
- `Start()` не вызывается, корутины стоят, `Post` на главный поток не выполняется во время синхронной загрузки данных
- `Player.log` не обновляется (застывает на старой дате)
- Фиксы: `Application.runInBackground = true` в Awake; статические тесты — **в фоновом потоке**; живые тесты — запуск в интерактивной сессии 1 через **планировщик задач (schtasks, InteractiveToken)**

**LitJson:** итерация только по `Keys` с проверкой `IsObject` и пропуском meta-ключей (`"_comment"`) — прямой каст `kv.Value` в string падает `InvalidCastException`.

**Мод-система:** в `settings.json` протухший `strPathMods` на старый путь (`C:/Game/...`) ломал загрузку модов → сброшен в пустое (бэкап `settings.json.bak`), игра стала брать дефолт `Ostranauts_Data/Mods/`.

**Box-транзит:** однострочные длинные base64 обрезаются → wrapped base64 (76 симв.) + sha1-контроль каждого чанка.
