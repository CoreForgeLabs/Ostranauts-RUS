ИНСТРУКЦИЯ ПО УСТАНОВКЕ:

В архиве находятся две версии загрузчика:
• BepInEx_6 — ДЛЯ АКТУАЛЬНОЙ ВЕРСИИ ИГРЫ (Unity 6 / 2026 год, рекомендуется!)
• BepInEx_5 — для старых версий игры (до обновления движка на Unity 6)

УСТАНОВКА:
1. Зайдите в папку BepInEx_6 (или BepInEx_5 для старых версий).
2. Скопируйте ВСЁ её содержимое (папку BepInEx, файлы winhttp.dll,
   doorstop_config.ini и .doorstop_version) в корневую папку игры Ostranauts:
   (например: Steam\steamapps\common\Ostranauts\)
   так, чтобы winhttp.dll оказался в одной папке с Ostranauts.exe.
3. Запустите игру через Steam или Ostranauts.exe.
4. В Главном меню появится интерактивный космонавт с переключением языка.
5. Приятной игры, капитан!

О МОДИФИКАЦИИ:
- Полная адаптация и перевод интерфейса, терминологии и игровых механик (все 25 файлов).
- Естественная русская грамматика со склонениями имён, глаголов и местоимений.
- Модульные кириллические шрифты в высоком разрешении (SDF).
- Русифицированные экраны MFD, связи, реактора, создания персонажа и предметов.
- Возможность переключения языка на лету прямо из главного меню.
